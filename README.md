# Rosreestr Dashboard — стартовый прототип

Первая версия:
- загружает Excel локально в браузере;
- показывает список листов;
- проверяет ожидаемые листы;
- ищет блоки «Полный и точный реестр» и «УРД»;
- ничего не отправляет в GitHub.

## Загрузка в GitHub
1. Откройте репозиторий `rosreestr-dashboard`.
2. Add file → Upload files.
3. Загрузите `index.html`, `styles.css`, `app.js`.
4. Commit changes.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
